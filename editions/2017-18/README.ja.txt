Forza-WCCF 2017-18 - 0.1.0-alpha.1
==================================
(English: README.txt - Italiano: README.it.txt)
[注意] この日本語版は機械的な翻訳に近い下訳です。日本語話者による確認が必要です。

これはアルファ版です。遊べますが未完成で、テスターを必要としています。開始前に「このアルファ版にないもの」と「既知の問題」を
お読みください。

この版の新機能（未公開）
  - Python 不要: セットアップ、カードのカタログ、カード画像、ゲームの文字が Launcher.exe の中で動きます。インストールするものは
    ありません。ダウンロードも小さくなりました（python\ と scripts\ フォルダーはありません）。
  - オンラインプレイに対応しました。Launcher.exe で「オンライン」を選ぶと、ロビーに「対戦ルーム」が並びます。「ルームを作る」で
    4 文字のコードのルームができ、「クイックマッチ」は待っている一番古いルームに入る（なければ新しく作る）、
    両者が「準備OK」を押すと 5 秒のカウントダウンでゲームが始まります。ロビーはキーボードとゲームパッドで操作できます。
  - オンラインではカードごとに専用の Aime ID が付くので、別々の家が同じクラブを共有することはありません。
  - 「クラブサーバー」と「ダイレクトVSリンク」の行は、オンラインの「アドレスを直接入力」の中に移りました。
  - ポーズ: P（または「一時停止」ボタン）で、この PC の試合を最長 20 秒止められます。
  - インストーラーの --kit は、この版の ZIP にも対応しました（インストーラーの README を参照）。

概要
  World Club Champion Football 2017-18 を、1 台の Windows PC で、1 席で、お客様ご自身のゲームファイルから動かします。ほかの家との
  オンライン VS は任意です。
  Forza-WCCF は、アーケード機の周辺機器とサーバーの代わりを務めます: ゲームサーバー（クラブとそのセーブ）、ネットワークとキーチップ、
  Aime カードリーダー、I/O ボード。ゲームウィンドウの周りには、筐体のボタンのパネルと、カード用のフォーメーションボードがあります。
  Forza-WCCF には元のファイルは一切含まれません。ゲーム由来のものはすべて、お客様のコピーから作られます。

必要なもの
  - Windows 10 または 11（64 ビット）
  - ご自身の復号済み 2017-18 ゲームフォルダー（client_Release.exe と control_Release.exe があるフォルダー）
    <ゲームの入手先: 所有者が記入>
  - それ以外は不要です。WSL も、ほかのインストールも要りません。

インストール（初回のみ）
  1. このダウンロードを専用のフォルダーに展開します。パスは英数字だけにしてください（例: C:\Games\Forza-WCCF-2017-18）。
  2. Launcher.exe を実行します。署名のないプログラムとして Windows が警告することがあります（「既知の問題」を参照）。
  3. 「セットアップと更新」を開き、ゲームフォルダーを選んで「セットアップ / 修復」を押します。セットアップは、ゲームのプログラムの
     保護付きコピー（元のフォルダーは変更されません。元のプログラムは original\ に保管されます）、カードのカタログ、カード画像を作ります。約 1 分かかります。もう一度実行すると、
     確認と修復を行います。
  2010-11 版と 2017-18 版のインストールは別々で、ゲームファイル、データ、ログ、セーブもそれぞれ独立しています。同じ PC で同時には
  動かせません。どちらもローカルの同じポートを使うためです。片方を閉じてから、もう片方を起動してください。

遊び方
  Launcher.exe の「プレイ」を押します。ゲームの起動には約 30 秒かかります。Aime カードはエミュレートされます。クラブとそのセーブは
  この PC の data\save\gamesvr に保存されます（このフォルダーのバックアップを取ってください）。ゲームの文字は English / Italiano /
  日本語（オリジナル）から選べます。「プレイ」の前に Launcher.exe で選んでください。
  初めての場合: 新しいカードは、マネージャーライセンス、5 プレイのチュートリアル、クラブの設定から始まり、約 30 分かかります。
  PLAY の前に Launcher.exe で「チュートリアルを省略」にチェックを入れると、新しいカードには準備済みのクラブが与えられ、メイン画面から始まります。
  ゲームのウィンドウをクリックしてから、次のキーを使います:
      Enter   START（フリープレイ: コインは自動で入ります）
      X       PRESS（決定）        C   SHOOT        B   KEEPER
      S       DATA                 D   KEY PLAYER
      矢印    戦術: 上 CENTRAL、下 COUNTER、左 L-SIDE、右 R-SIDE
      I       Aime カードの出し入れ   5   コイン 1 枚   F1  テストメニュー
  パネルのボタンをクリックしても操作できます: 三角形（CENTRAL、COUNTER、L-SIDE、R-SIDE）、PRESS、DATA、SHOOT、KEEPER、KEY PLAYER、
  START。パネルのフォーメーションボードにはカードが表示されます。ドラッグで移動し、別のカードの上にドロップすると入れ替わります。
  2D コード付きのレアカードも使えます。ゲームサーバーが登録済みとして一覧に出します。
  起動後は早めにカードを入れてください。試合後はカードを出し（I）、ゲームのウィンドウを閉じます。
  P       この PC の試合を一時停止（最長 20 秒で自動再開。P か「再開」で早く戻せます。次の一時停止は 10 秒後）。オンライン中、
          別の席が接続されているとき、プロジェクターが動いているときはできません。キーは KEYS で変えられます。

オンライン（家どうしの VS）
  1. Launcher.exe で「オンライン」を選びます。「アドレスを直接入力」を開いてサーバーのアドレス（HOST または HOST:PORT）を入力します。
     ロビーは入力したすべてのアドレスに問い合わせます。プロジェクトのサーバーは許可リストにあるアドレスだけを受け付けます。
     運営者にあなたのアドレスの追加を依頼してください。2017-18 では「店舗」は使えません。一覧は「対戦ルーム」です。
  2. 「ルームを作る」でルームが作られ、コード（例: K7QM）が表示されます。友だちにコードを伝えると、友だちはそのルームを選んで
     「参加」を押します。「クイックマッチ」は待っている一番古いルームに入るか、新しく作ります。「退出」（Esc）で席を離れます。
  3. 各プレイヤーが「準備OK」を押します。両者が準備OKになると 5 秒のカウントダウンでゲームが始まります。準備OKのまま約 90 秒
     誰も来ないときは、CPU チームでゲームが始まります。
  4. ロビーのキー: 上下で行、左右または Tab で一覧、Enter で参加または準備OK、H でルームを作る、F5 で更新、Esc で退出。
     ゲームパッド: 十字キーか左スティックで移動、A = Enter、B = Esc、X = 更新、Y = ルームを作る、LB/RB = 一覧の切り替え。
  「クラブサーバー」（「アドレスを直接入力」の中）はクラブの保管先です。空欄なら選んだサーバーを使います。「ダイレクトVSリンク」
  （relay.wccf.it）は、あなたの PC と相手の PC をつなぎます。初回は Windows ファイアウォールが Launcher.exe について確認することが
  あります。許可すると直接接続になり、拒否してもリレー経由で VS はできますが、遅延が増えます。チェックを外すとリンクを使いません。
  「このPC」を選ぶと、この PC のクラブに戻ります。

このアルファ版にないもの
  - キャリアモード
  - LAN プレイと複数席の店舗（1 台の PC に 1 席。オンラインは家どうしの VS のみ）
  - 描画スケール

既知の問題
  - 約 90 分放置すると、コントロールプログラムが落ちることがあります。ゲームを閉じて起動し直してください。クラブは保存されています。
  - チーム登録で、先に進むまで約 95 秒待つことがあります。
  - 家どうしのオンライン VS は、2 台の PC でまだ最後まで遊んで確認されていません。テストとしてお試しください。
  - プログラムには署名がありません。Windows SmartScreen が「Windows によって PC が保護されました」と表示することがあります。
    「詳細情報」を選び、「実行」を押してください。Microsoft Defender がファイルを検出した場合は、Defender を無効にせず、
    ファイル名と Defender のメッセージを報告してください（「ログと不具合報告」を参照）。
  - ウイルス対策ソフトが overlay\inject.exe（パネルをゲームに読み込みます）と bin\winmm.dll（ゲームと Windows の間に入ります）を
    好まないことがあります。ソースコードは source\ にあります。

ウイルス対策と SmartScreen
  プログラムには署名がありません。動作のため、Launcher.exe は Windows のデバッグインターフェイスでゲームのプログラムを起動し、
  Forza-WCCF の DLL を 2 つ読み込ませます: forza_panel.dll はゲームのフレームにパネルを描画し、netguard.dll と保護済みコピーの
  wccfnet.dll はゲームのネットワークアダプター呼び出しを置き換えて、この PC のネットワークのリース（lease）をゲームが
  解除できないようにします。セットアップが変更するのはゲームのプログラムのコピーだけで、元のプログラムは original\ に退避し、
  変更しません。ウイルス対策ソフトはチートツールと同様に扱うことがあります。各リリースのファイルは、公開前に誤検出として
  Microsoft に提出します。
  それでも Defender が検出した場合: Defender を無効にしないでください。検出名を控え、公式ダウンロード由来のファイルに限って
  保護の履歴から復元し、報告してください: <報告先リンク: 所有者が記入>
  SmartScreen: 「詳細情報」を選び、「実行」を押してください。

安全性
  Forza-WCCF は、この PC のネットワーク設定（アドレス、ルート、ファイアウォール）を決して変更しません。ゲーム自身のネットワーク
  呼び出しは、起動前に保護用のものに置き換えられ、保護が整っていない場合 Launcher.exe はゲームを起動しません。ゲームがパブリッシャーの
  ホストに接続することはなく、すべてこの PC 上の代役に向けられます。control_Release.exe のネットワーク使用を Windows が確認してくる
  ことがありますが、どちらを選んでもすべてこの PC の中で完結します。

ログと不具合報告
  ログは data\logs にあり、前回の実行分は data\logs\previous にあります。不具合は、ログを添えて報告してください。パネルの SETTINGS に
  SEND LOGS があります（送信先のサーバーアドレスが必要です。ない場合は data\logs を ZIP にして手動で送ってください）。何をして何が
  起きたかも書いてください。Defender や SmartScreen の警告の場合は、ファイル名と警告の文面を添えてください。

フォルダー
  bin\       winmm.dll（フック）、FPR_Emu.exe（カードテーブル用ヘルパー）、logowin.exe（代用）、forza-server.exe
  overlay\   forza_panel.dll（パネル）、inject.exe、netguard.dll（ネットワーク保護）、skin.tex。セットアップがカタログとカード画像を追加します
  fonts\     パネルのフォントとライセンス
  english\, italian\   ゲームの英語・イタリア語テキスト（テキストのみ）
  source\    bin\ と overlay\ のプログラムの C ソース
  data\      お客様の PC 上に作られます: 設定、セーブ（save\gamesvr）、ログ
