Forza-WCCF 2017-18（アルファ版）
================================
(English: README.txt - Italiano: README.it.txt)
[注意] この日本語版は日本語話者による確認がまだ済んでいません。

アルファ版です。遊べますが未完成で、テスターを募集しています。
先に「このアルファ版にないもの」と「既知の問題」をお読みください。

概要
  World Club Champion Football 2017-18 を、ご自身のゲームファイルから 1 台の Windows PC・1 席で遊べます。ほかの家との
  オンライン VS もできます（任意）。Forza-WCCF がアーケードのハードウェアとサーバーの代わりをします: ゲームサーバー
  （クラブとセーブ）、ネットワークとキーチップ、Aime カードリーダー、I/O ボード。ゲーム画面の周りのパネルには、筐体の
  ボタンとカード用のフォーメーションボードがあります。Forza-WCCF にオリジナルのファイルは含まれません。ゲームのデータは
  すべてお手持ちのコピーから作ります。

必要なもの
  - Windows 10 または 11（64 ビット）
  - ご自身の復号済み 2017-18 ゲームフォルダー（client_Release.exe と control_Release.exe があるフォルダー）。ゲームは
    含まれていません。

インストール（初回のみ）
  1. ダウンロードしたファイルを専用のフォルダーに展開します。パスは英数字だけに
     してください（例: C:\Games\Forza-WCCF-2017-18）。
  2. Launcher.exe を起動します。署名のないプログラムとして Windows が警告したら、
     「ウイルス対策と SmartScreen」を参照してください。
  3. 右上で言語を選びます: English / Italiano / 日本語。
  4. 「セットアップ」を開き、ゲームフォルダーを選んで（「参照」またはドラッグ）「設定する」を押します。
     約 1 分かかります。ゲームフォルダーは変更されず、元のプログラムは original\ に残ります。
     もう一度「設定する」を押すと確認と修復、「設定を元に戻す」で元の状態に戻ります。
  2010-11 版と 2017-18 版は別々にインストールされますが、同じローカルポートを使います。
  片方を閉じてからもう片方を起動してください。

ランチャー
  プレイ          「プレイ場所」（このPC / オンライン）を選んで「プレイ」。「ゲームを終了」でゲームを閉じます（試合中は
                  「もう一度押す」）。
  セットアップ    ゲームフォルダー、「設定する」、「設定を元に戻す」、「カード画像」
                  （「ゲームから」または「高画質パック」。パックは「パックを選択」で指定）、「チュートリアルを省略」。
  アップデート    公開中のリリースが一覧に出ます。選んで「アップデート」を押すと、ゲームの設定も自動でやり直します。
                  クラブと設定は残ります。
  詳細            ランチャーの処理内容。「コピー」と「ログを保存」があります。
  右上の言語は、ランチャーとゲームの文字の両方に効きます: English、Italiano、日本語（オリジナルの日本語）。
  ゲームには次の「プレイ」から反映されます。

遊び方
  「プレイ」を押すと、約 30 秒でゲームが始まります。Aime カードはエミュレートされます。クラブとセーブは
  data\save\gamesvr にあります。このフォルダーはバックアップしてください。
  新しいカードは、マネージャーライセンス、5 プレイのチュートリアル、クラブ作成から始まります（約 30 分）。省略するには、
  「プレイ」の前に「セットアップ」の「チュートリアルを省略」をオンにします。新しいカードに完成したクラブが付き、
  メイン画面から始まります。
  起動したら早めにカードを入れてください。試合後はカードを出し（I）、ゲームのウィンドウを閉じます。

キー
  まずゲームのウィンドウをクリックします。
      Enter   START（フリープレイ: コインは自動で入ります）
      X       PRESS（決定）        C   SHOOT        B   KEEPER
      S       DATA                 D   KEY PLAYER
      矢印    戦術: 上 CENTRAL、下 COUNTER、左 L-SIDE、右 R-SIDE
      I       Aime カードの出し入れ   5   コイン
  パネルのボタンでも同じ操作ができます: 三角形（CENTRAL、COUNTER、L-SIDE、R-SIDE）、PRESS、DATA、SHOOT、KEEPER、
  KEY PLAYER、START。キーとコントローラーのボタンは「キー設定」で変更できます。
  フォーメーションボード: カードをドラッグで移動、別のカードの上に落とすと入れ替え。「＋カード」でカタログが開きます。
  2D コード付きのレアカードも使えます。

オンライン
  1. 「プレイ」で「オンライン」を選びます。「アドレスを直接入力」を開き、サーバーのアドレス（HOST または HOST:PORT）を
     入力します。プロジェクトのサーバーは許可リストにあるアドレスだけを受け付けるので、
     運営者に追加を頼んでください。「ゲームセンター」では「ゲームセンターを開く」でゲームセンターができ、
     コードが出ます。相手はそのコードを「ルームコード」に入力するか、一覧のゲームセンターのルームを選んで
     「参加」を押します。「ゲームセンターを開く」の下の「ゲームセンター名」が、一覧でほかの人に見える名前です。
  ロビーのキー: 上下で行、Enter で「参加」、H で「ゲームセンターを開く」、F5 で更新、Esc で「退出」。
  ゲームパッド: 十字キーか左スティックで移動、A = Enter、B = Esc、X = 更新、Y = ゲームセンターを開く。
  「アドレスを直接入力」の中:
    クラブサーバー        クラブの保管先。空欄なら選んだサーバー。
    ダイレクトVSリンク    あなたの PC と相手の PC を直接つなぎます（relay.wccf.it）。オフにするとリレー経由になります。
  初回は Windows ファイアウォールが Launcher.exe について確認してくることがあります。許可してください。拒否すると
  VS はリレー経由になり、遅延が増えます。オンラインではカードごとに専用の Aime ID が付くので、別の家と同じクラブを
  共有することはありません。
  「このPC」を選ぶと、この PC のクラブに戻ります。

このアルファ版にないもの
  - キャリアモード
  - 描画スケール

既知の問題
  - 約 90 分放置すると、コントロールプログラムが落ちることがあります。ゲームを再起動してください。クラブは残っています。
  - チーム登録で約 95 秒止まることがあります。
  - オンラインの試合が約 2 分後に CPU 相手に切り替わることがあります。AMD と Intel の PC の間で多く起きます。

ウイルス対策と SmartScreen
  プログラムには署名がなく、Forza-WCCF はゲームのプログラムのコピーを書き換えます（オリジナルは変更せず original\ に
  残します）。そのためウイルス対策ソフトがチートツールと見なし、bin\winmm.dll を検出することがあります。ソースは
  SOURCE.txt のリンク先にあります。各リリースのファイルは、公開前に誤検出として Microsoft に報告しています。
  SmartScreen（「Windows によって PC が保護されました」）: 「詳細情報」を選び、「実行」を押してください。
  Defender が検出したとき: Defender は無効にしないでください。検出名を控え、公式ダウンロードのファイルであれば
  「保護の履歴」から復元し、報告してください: https://github.com/Forza-WCCF/Forza-WCCF/issues

安全性
  Forza-WCCF がこの PC のネットワーク設定（アドレス、ルート、ファイアウォール）を変えることはありません。ゲームが
  パブリッシャーのサーバーに接続することもなく、すべてこの PC 上の代役につながります。ゲームは必ず Launcher.exe から
  起動してください。「設定する」で作っていないコピーは起動しません。control_Release.exe のネットワーク使用について
  Windows が確認してきたら、どちらを選んでも構いません。

ログと不具合報告
  ログは data\logs に、前回の分は data\logs\previous にあります。不具合は、ログを添えて、何をして何が起きたかを
  書いて報告してください。送り方: Launcher.exe の「問題を報告」、パネルの「設定」にある「ログを送信」（サーバーの
  アドレスが必要）、または「ログを保存」で保存したファイルを送る。Defender や SmartScreen の警告なら、ファイル名と
  警告の文面も添えてください。

フォルダー
  bin\       Forza-WCCF のプログラム: 代役、カードテーブル用ヘルパー
  overlay\   パネル。「設定する」でカタログとカード画像が追加されます
  fonts\     パネルのフォントとライセンス
  english\, italian\   ゲームの英語・イタリア語テキスト
  data\      お使いの PC で作られます: 設定、セーブ（save\gamesvr）、ログ
