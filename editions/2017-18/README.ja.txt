Forza-WCCF 2017-18 - 0.1.0-alpha.1
==================================
(English: README.txt - Italiano: README.it.txt)
[注意] この日本語版は機械的な翻訳に近い下訳です。日本語話者による確認が必要です。

アルファ版です。遊べますが未完成で、テスターが必要です。先に「このアルファ版にないもの」と「既知の問題」をお読みください。

この版の新機能（未公開）
  - Python 不要: セットアップ、カードのカタログ、カード画像、ゲームの文字が Launcher.exe の中で動きます。ダウンロードも
    小さくなりました（python\ と scripts\ フォルダーはありません）。
  - オンラインプレイ。Launcher.exe で「オンライン」を選ぶと、ロビーに「対戦ルーム」が並びます。「ルームを作る」で 4 文字の
    コードのルームができ、「クイックマッチ」は待っている一番古いルームに入ります（なければ新しく作成）。両者が「準備OK」を
    押すと、5 秒のカウントダウンでゲームが始まります。キーボードとゲームパッドで操作できます。
  - オンラインではカードごとに専用の Aime ID が付くので、別々の家が同じクラブを共有することはありません。
  - 「クラブサーバー」と「ダイレクトVSリンク」の行は、オンラインの「アドレスを直接入力」の中に移りました。
  - ポーズ: P（または「一時停止」ボタン）で、試合を最長 20 秒止められます。
  - インストーラーのパッケージ指定は、この版の ZIP に対応しました（インストーラーの README を参照）。

概要
  World Club Champion Football 2017-18 を、1 台の Windows PC、1 席で、ご自身のゲームファイルから動かします。ほかの家との
  オンライン VS は任意です。Forza-WCCF はアーケード機のハードウェアとサーバーの代わりをします: ゲームサーバー（クラブとセーブ）、
  ネットワークとキーチップ、Aime カードリーダー、I/O ボード。ゲームウィンドウの周りのパネルに、筐体のボタンと、カード用の
  フォーメーションボードがあります。Forza-WCCF に元のファイルは含まれません。ゲーム由来のものはすべてお客様のコピーから作られます。

必要なもの
  - Windows 10 または 11（64 ビット）
  - ご自身の復号済み 2017-18 ゲームフォルダー（client_Release.exe と control_Release.exe があるフォルダー）
    <ゲームの入手先: 所有者が記入>
  - それ以外は不要です（WSL も不要）。

インストール（初回のみ）
  1. このダウンロードを専用のフォルダーに展開します。パスは英数字だけにしてください（例: C:\Games\Forza-WCCF-2017-18）。
  2. Launcher.exe を実行します。署名のないプログラムとして Windows が警告することがあります（「既知の問題」を参照）。
  3. 「セットアップと更新」を開き、ゲームフォルダーを選んで「セットアップ / 修復」を押します（約 1 分）。ゲームのプログラムの
     保護付きコピー、カードのカタログ、カード画像を作ります。ゲームフォルダーは変更されず、元のプログラムは original\ に
     保管されます。もう一度実行すると、確認と修復を行います。
  2010-11 版と 2017-18 版は別々で、ゲームファイル、データ、ログ、セーブもそれぞれ独立しています。ローカルの同じポートを使う
  ため、片方を閉じてからもう片方を起動してください。

遊び方
  Launcher.exe の「プレイ」を押します。ゲームは約 30 秒で起動します。Aime カードはエミュレートされます。クラブとセーブは
  data\save\gamesvr に保存されます（バックアップを取ってください）。ゲームの文字は English / Italiano / 日本語（オリジナル）から
  選べます。「プレイ」の前に Launcher.exe で選んでください。
  新しいカードは、マネージャーライセンス、5 プレイのチュートリアル、クラブの設定から始まります（約 30 分）。省略するには、
  「プレイ」の前に Launcher.exe で「チュートリアルを省略」にチェックを入れます。新しいカードに準備済みのクラブが与えられ、
  メイン画面から始まります。
  ゲームのウィンドウをクリックしてから、次のキーを使います:
      Enter   START（フリープレイ: コインは自動で入ります）
      X       PRESS（決定）        C   SHOOT        B   KEEPER
      S       DATA                 D   KEY PLAYER
      矢印    戦術: 上 CENTRAL、下 COUNTER、左 L-SIDE、右 R-SIDE
      I       Aime カードの出し入れ   5   コイン 1 枚   F1  テストメニュー
  パネルのボタンをクリックしても操作できます: 三角形（CENTRAL、COUNTER、L-SIDE、R-SIDE）、PRESS、DATA、SHOOT、KEEPER、KEY PLAYER、
  START。パネルのフォーメーションボードにはカードが表示されます。ドラッグで移動し、別のカードの上にドロップすると入れ替わります。
  2D コード付きのレアカードも使えます（ゲームサーバーが登録済みとして一覧に出します）。
  起動後は早めにカードを入れてください。試合後はカードを出し（I）、ゲームのウィンドウを閉じます。
  P       試合を一時停止（最長 20 秒で自動再開。P か「再開」で早く戻せます。次の一時停止は 10 秒後）。オンライン中、別の席が
          接続されているとき、プロジェクターが動いているときはできません。キーは KEYS で変更できます。

オンライン（家どうしの VS）
  1. Launcher.exe で「オンライン」を選びます。「アドレスを直接入力」を開いてサーバーのアドレス（HOST または HOST:PORT）を入力します。
     ロビーは入力したすべてのアドレスに問い合わせます。プロジェクトのサーバーは許可リストにあるアドレスだけを受け付けます。
     運営者にあなたのアドレスの追加を依頼してください。2017-18 では「店舗」は使えません。「対戦ルーム」を使います。
  2. 「ルームを作る」でルームが作られ、コード（例: K7QM）が表示されます。友だちにコードを伝え、友だちがそのルームを選んで
     「参加」を押します。「クイックマッチ」は待っている一番古いルームに入るか、新しく作ります。「退出」（Esc）で席を離れます。
  3. 各プレイヤーが「準備OK」を押すと、5 秒のカウントダウンでゲームが始まります。準備OKのまま約 90 秒誰も来ないときは、
     CPU チームでゲームが始まります。
  4. ロビーのキー: 上下で行、左右または Tab で一覧、Enter で参加または準備OK、H でルームを作る、F5 で更新、Esc で退出。
     ゲームパッド: 十字キーか左スティックで移動、A = Enter、B = Esc、X = 更新、Y = ルームを作る、LB/RB = 一覧の切り替え。
  「クラブサーバー」（「アドレスを直接入力」の中）はクラブの保管先です。空欄なら選んだサーバーを使います。「ダイレクトVSリンク」
  （relay.wccf.it）は、あなたの PC と相手の PC をつなぎます。チェックを外すと使いません。初回は Windows ファイアウォールが
  Launcher.exe について確認することがあります。直接接続には許可してください。拒否した場合はリレー経由になり、遅延が増えます。
  「このPC」を選ぶと、この PC のクラブに戻ります。

このアルファ版にないもの
  - キャリアモード
  - LAN プレイと複数席の店舗（1 台の PC に 1 席。オンラインは家どうしの VS のみ）
  - 描画スケール

既知の問題
  - 約 90 分放置すると、コントロールプログラムが落ちることがあります。ゲームを再起動してください。クラブは保存されています。
  - チーム登録で約 95 秒待つことがあります。
  - 家どうしのオンライン VS は、2 台の PC でまだ最後まで遊んで確認されていません。テストとしてお試しください。
  - プログラムには署名がありません。SmartScreen と Defender については「ウイルス対策と SmartScreen」を参照してください。
  - ウイルス対策ソフトが overlay\inject.exe（パネルをゲームに読み込みます）と bin\winmm.dll（ゲームと Windows の間に入ります）を
    検出することがあります。ソースは source\ にあります。

ウイルス対策と SmartScreen
  プログラムには署名がありません。Launcher.exe は Windows のデバッグインターフェイスでゲームのプログラムを起動し、
  Forza-WCCF の DLL を 2 つ読み込ませます: forza_panel.dll はゲームのフレームにパネルを描画し、netguard.dll と保護済みコピーの
  wccfnet.dll はゲームのネットワークアダプター呼び出しを置き換えて、この PC のネットワークのリース（lease）をゲームが
  解除できないようにします。セットアップが変更するのはゲームのプログラムのコピーだけで、元のプログラムは original\ に退避し、
  変更しません。ウイルス対策ソフトはチートツールと同様に扱うことがあります。各リリースのファイルは、公開前に誤検出として
  Microsoft に提出します。
  SmartScreen（「Windows によって PC が保護されました」）: 「詳細情報」を選び、「実行」を押してください。
  Defender が検出した場合: Defender を無効にしないでください。検出名を控え、公式ダウンロード由来のファイルに限って
  保護の履歴から復元し、報告してください: <報告先リンク: 所有者が記入>

安全性
  Forza-WCCF は、この PC のネットワーク設定（アドレス、ルート、ファイアウォール）を決して変更しません。起動前に、ゲーム自身のネットワーク
  呼び出しが保護用のものに置き換えられます。保護が整っていない場合、Launcher.exe はゲームを起動しません。ゲームがパブリッシャーの
  ホストに接続することはなく、すべてこの PC 上の代役に向けられます。control_Release.exe のネットワーク使用を Windows が確認して
  きたら、どちらを選んでも構いません。

ログと不具合報告
  ログは data\logs にあり、前回の実行分は data\logs\previous にあります。不具合は、ログを添え、何をして何が起きたかも書いて報告してください。
  パネルの SETTINGS に SEND LOGS があります（サーバーアドレスが必要です。ない場合は data\logs を ZIP にして手動で送ってください）。
  Defender や SmartScreen の警告の場合は、ファイル名と警告の文面を添えてください。

フォルダー
  bin\       winmm.dll（フック）、FPR_Emu.exe（カードテーブル用ヘルパー）、logowin.exe（代用）、forza-server.exe
  overlay\   forza_panel.dll（パネル）、inject.exe、netguard.dll（ネットワーク保護）、skin.tex。セットアップがカタログとカード画像を追加します
  fonts\     パネルのフォントとライセンス
  english\, italian\   ゲームの英語・イタリア語テキスト（テキストのみ）
  source\    bin\ と overlay\ のプログラムの C ソース
  data\      お客様の PC 上に作られます: 設定、セーブ（save\gamesvr）、ログ
